### Tamas Demeter

I build automation and AI systems for operations teams: n8n pipelines, Claude-based agents, and the small tools that hold them together. Based in Hungary. Most client work lives in private repos, the public ones below are what I can show.

**Public work**

- [meeting-capture-kit](https://github.com/demtomi/meeting-capture-kit): dual-track meeting audio capture on macOS with a Core Audio process tap, plus a transcriber on your own ElevenLabs key. Every check runs with no mic grant, no screen-recording grant and no network, so the suite runs in CI.
- [n8n-coach](https://github.com/demtomi/n8n-coach): a chatbot that answers n8n questions and debugs pasted workflows, using retrieval over the n8n docs and Claude.
- [claude-code-skills-starter-kit](https://github.com/demtomi/claude-code-skills-starter-kit): build custom skills for Claude Code. Three working examples, templates and the spec.
- [social-media-agent-toolkit](https://github.com/demtomi/social-media-agent-toolkit): a five-skill Claude Code pipeline for social content, from idea to analytics.

**How I work**

Changes land as pull requests with tests run before merge. I measure before I claim a fix works, and the commit messages say what was measured.
